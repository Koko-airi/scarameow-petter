# 🍵 Scarameow Teahouse Petting Sanctuary

A warm, cozy Inazuma teahouse clicker/pet simulator starring the grumpy teacup Wanderer-cat!

## 🎮 Play Online
Visit the live site: [GitHub Pages](https://koko-airi.github.io/scarameow-petter/)

## ✨ Features
- **Tactile 3D Buttons & Hearth Aesthetic**: Roasted cedar timber, matcha moss, and honey amber.
- **Synthesized Audio**: Procedural kitten chirps, chimes, and purr rumbles via Web Audio API.
- **11 Teahouse Caretakers**: From Cardboard Boxes to the Shouki no Meow Mech.
- **Zoomies & Golden Feathers**: Rapid click combos and drifting bonuses.
- **Auto-Save & Export**: Continuous save in localStorage with exportable codes.

## 🚀 Deployment
Automatically built and deployed to GitHub Pages via GitHub Actions on every push to `main`.
